# StreamFlow

Live streaming platform built with React, Express, MongoDB, and WebRTC.

## Quick Start

### 1. Start MongoDB
```bash
mongod
```

### 2. Start Backend
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### 3. Start Frontend
```bash
cd frontend
npm install
npm run dev
```

## How to Use

1. Register/login and go to My Stream dashboard
2. Click Go Live to start streaming
3. Others can watch your stream via WebRTC
4. Chat with viewers in real-time
